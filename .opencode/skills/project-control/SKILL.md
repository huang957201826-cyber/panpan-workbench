# 批次推进（总控）

## 触发词
「按批次推进」「意见收口」「预审」「放行」「只交付最终版」「像素级」「照搬不要重写」「复盘」。

## 六步，缺一步不进下一步
1. 意见收口 → 编号清单，一页，不再新增口径
2. 总方案 + ADR → 必填「复用哪份现成实现，来源是什么」
3. 预审 → 独立窗口，只判三类阻塞
4. 放行 → 冻结方案 + 阶段顺序
5. 垂直切片执行 → 一次一页，walking skeleton 先行
6. 收口 → 产物 + 文档 + 安装

## 三个角色
- 总控：收口、方案、派发、验收、安装；不写业务代码
- 执行窗口：唯一写代码；不写方案、不自审
- 审查窗口：只读；全程一个，不每阶段新开

## 阻塞只有三类
丢数据 / 泄密钥 / 构建安装不可用。其余记 known-limits。

## 每批 DoD
- 验收命令在动手前写死，且 exit 0
- 产物三选一以上：并排截图 / 来源 diff / 测试数
- 独立复审 APPROVE
- 状态文档已更新
- 本地提交，不 push、不打 tag

## 铁律
- 能原样复制的绝不重写；复制件必须登记来源并过 provenance 校验
- 一次只改一页；出问题 revert 单批
- 同一处第二次失败：停，换路线，不硬试第三种写法
