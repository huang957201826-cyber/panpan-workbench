## 2. B02-1B：数据安全、预置 API 与错误兜底

### 做

- **P1-40 错误边界**：顶层 ErrorBoundary；fallback 提供重新加载、打开日志、复制诊断（脱敏）；`start()` 启动失败也不白屏。
- **P1-41 删除保护（完整快照版）**：删除任务/项目/画布前，先用现有导出链路生成一份**含图片文件**的 ZIP 快照到 `data/backups/delete-<timestamp>.zip`；快照失败则中止删除。设置页“最近删除快照”列出最近 5 份，恢复走现有 ZIP 导入。不新建回收站表、不做 30 天后台清理；图片随 ZIP 保存，删除后的原图清理不会影响恢复。
- **P2-19 API Key 加密**：Windows DPAPI（`CryptProtectData`）或凭据管理器；旧明文迁移后清除；导出仍不含 Key。
- **P2-25 数据库韧性**：启动 `PRAGMA quick_check`；迁移前 `VACUUM INTO` 快照保留 3–5 份；损坏时提示恢复。
- **P2-24 磁盘预检**：生成/导出/写图前检查剩余空间；磁盘不足明确提示并清理临时文件。
- **F-01/F-02/F-03 预置 API**：
  - 预置只留「默认」+「特惠 API」；删除 APIMart/摸鱼/JuCodex/MaruCode/Sublyx/custom-apimart。
  - 特惠：注册送 10 刀 + `https://api.tehui.xyz/sign-up?aff=rf9W`，baseUrl `https://api.tehui.xyz/v1`，模型 `gpt-image-2.5`，Key 留空。
  - 被现有任务引用的旧 profile 保留（兼容例外），其余旧广告配置删除。
  - 构建前后扫描 `apiKey`/`api-sz-link`/`jucodex`；根 `npm run build` 也必须扫描；命中即失败。
- **P2-11 发布检查**：`scripts/release-check.mjs` 校验版本一致性、预置、dist、候选安装包 SHA（必须匹配 GATES）；本批不检查 `RELEASE.md`，`--release` 模式留给 B02-3 P2-20 收口后使用。
- 顺手收口 B02-1A 非阻塞项：`removeTasks` try/finally、`clearData` 清理顺序、Agent 对话 flush 说明。

### 验收

- 预置干净副本只有两条；真实库被引用旧 profile 保留且报告写明。
- 恶意预置/恶意 dist 让根构建或 release-check 失败；正常构建通过。
- 删除含输入图/输出图的任务后，可从删除 ZIP 快照恢复任务、输入图、输出图，图片数量/哈希与删除前一致；项目/画布快照同样覆盖其任务图片；Key 落盘为密文且导出不含 Key。
- DB 损坏可检测/恢复；磁盘不足有明确提示。
- 错误边界单测通过，复制诊断不含 `sk-`/Bearer 原文。

### B02-1B 真实数据迁移门禁

P2-19/P2-25/P1-41 会改写真实 settings/DB，不能只跑合成测试库：

1. 先确认 B02-1A 双备份仍有效；再做一份 `panpan-b02-1b-migration-data` 真实数据副本。
2. 在副本上执行明文 Key 加密迁移、DB schema/quick_check、删除快照；记录迁移前后清单哈希、任务/项目/画布数、Key 可解密、导出不含 Key。
3. 副本通过后，才允许受控首次真实启动；真实目录 pre/post 哈希/任务数必须记录。
4. P2-19 迁移失败不得删除旧明文 Key；P2-25/P1-41 失败用副本/备份回滚。
5. 任何一步失败：停止，真实目录不写，报告第一个失败门。
