# UI 反馈第五轮：九宫格/画布工具栏统一（2026-11-07，待实现）

## 问题

九宫格右上角有：
- 搜索提示词/模型
- 状态筛选（全部/完成/失败/生成中）
- 只看收藏
- 多选模式
- 全选 / 批量收藏 / 批量下载 / 批量删除
- 视图切换（画布/九宫格）

无限画布右上角只有视图切换和少量控制，没有搜索/筛选/收藏/批量；来回切换时位置和功能都跳，用户觉得不合理。

## 目标

**九宫格和无限画布只是展示形式不同，功能必须同一套。**

- 同一套顶部工具栏，固定在右上角，两种模式位置一致，不来回跳。
- 画布模式直接使用同一搜索/筛选/收藏/多选/批量功能。
- 九宫格已有的功能照搬到画布，不减少。
- 画布保留自己特有的底部右下缩放/全览；九宫格不需要缩放条。
- 九宫格背景纯色；画布保留点阵（已确认）。

## 共享工具栏内容

1. 搜索框：提示词 / 模型（同一 query，两种模式共用过滤结果）。
2. 状态筛选：全部 / 完成 / 失败 / 生成中。
3. 只看收藏。
4. 多选模式：
   - 画布：复用现有框选/点选多选；九宫格：卡片多选。
   - 全选（当前过滤结果）
   - 批量收藏
   - 批量下载
   - 批量删除（确认 + 删除快照）
5. 视图切换：画布 / 九宫格（右上，固定位置）。
6. 选中数量、清除选择。

## 实现建议

- 抽一个 `StudioViewToolbar` 共享组件，放在 StudioShell 的右上固定层；两种模式渲染同一组件。
- 删除 `CardGridView` 内部的重复 headerControls/视图切换，避免两套。
- 画布的 `visibleNodes` 使用与九宫格相同的 `filteredTasks`（按搜索/状态/收藏过滤）。
- 参考图图片节点不参与“任务搜索/筛选”隐藏：素材库始终可见；批量操作只针对任务节点。
- 视图切换、搜索框、按钮位置在两种模式完全一致；切换时不重置搜索/筛选（可选保留状态）。
- 空结果时画布显示“没有匹配任务”，不要空白无提示。

## 验收

- 九宫格与画布右上角工具栏位置一致、功能一致。
- 搜索“梨”/模型名，两种模式过滤结果一致。
- 状态筛选、只看收藏、多选/全选/批量收藏/批量下载/批量删除在画布可用。
- 切换模式不跳位置、不丢搜索条件。
- 九宫格纯色背景，画布点阵背景。

## 补充：左下角设置按钮

- 现状：左侧栏底部设置用的是滑杆（Sliders）图标，不够明显。
- 需求：换成经典齿轮（Settings）图标，提高可见性。
- 建议：齿轮图标略大、颜色对比提高；hover 蓝色高亮 + tooltip“设置”；保留底部位置，不新开入口。
- 不改设置页内容，只改入口图标/可见性。
