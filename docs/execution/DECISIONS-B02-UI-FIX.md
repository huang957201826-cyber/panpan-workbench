## 8. 用户补充口径（2026-11-07，覆盖前面不明确处）

### 8.1 参考图唯一数据源

- 拖一张图进软件：画布上出现该图节点，同时输入框/参考图架出现同一张图。
- 底层只存一份；画布节点与输入框指向同一图像记录，但两者职责不同：
  - **画布是素材与成品的总库/展示面**。
  - **输入框只是“本次生成要使用哪些素材”的选择器**。
- 在输入框删除某个素材：只取消本次选择，**画布上的该素材必须保留**。
- 在画布删除该图节点：素材从总库移除，输入框中该图显示“缺失状态”，不静默消失、不保留可用的假缩略图。
- 输入框排序/替换只影响选择顺序，不影响画布素材是否存在。
- 旧项目里的参考图不迁移、不处理，保留原样；只对新建/新拖入的图应用新规则。

### 8.2 生图后输入与参考图不变（原型行为）

- 提交一次生图后：**输入框提示词保持原样，参考图保持原样**。
- 不自动追加 `@图1`，不自动把生成结果设为参考图，不清空输入，不改变参考图顺序。
- 只有用户显式点击“设为参考图”/“编辑输出”等入口，才把输出加入参考图。
- 生成结果只作为画布上的任务/图片节点存在，不自动进入输入框。
- 本轮实测观察到“生成后 referenceImageIds 0→1、提示词自动追加 @图1”，按本条视为需要纠正的行为，不作为设计。
- 任何“提交后清空输入/自动引用输出”的旧逻辑都不得覆盖本条。

### 8.3 工作流/技能库占位

- 保持上一版形式：三个大按钮都在；点击工作流/技能库显示“正在开发，敬请期待”的占位内容。
- 不恢复已删除的大页面，不新增功能，只恢复入口和占位。

### 8.4 界面缩放

  - 默认字号/按钮/图标/留白整体放大；
