# 技能库 V1（提示词收藏/快速引用）方案

- 日期：2026-11-07
- 目标：初代版本，快速可用；不做市场、社区、同步、AI 生成提示词。
- 参考产品（只借鉴交互，不复制代码/素材）：
  - Google AI Studio：Prompt Gallery / History，可搜索已保存提示词，点击加载回编辑器。
  - PromptHero / FlowGPT：卡片网格、标签筛选、提示词预览。
  - Notion Template Gallery：分类 + “使用模板”一键套用。

## 1. 用户流程

### 保存
- 输入台/画布任务右键/详情：**保存为技能**。
- 弹窗填写：名称、标签、分类、提示词（可编辑）、是否包含参数（尺寸/质量/模型）。
- 从画布任务保存时，默认带该任务的提示词与参数；参考图是否一起保存作为可选（V1 先不做图片快照，避免数据膨胀）。
- 客户自己整理的提示词可直接“新建技能”。

### 使用
- 左侧“技能库”按钮打开面板。
- 搜索标题/提示词/标签；按标签/分类筛选；置顶/收藏。
- 卡片显示：名称、提示词预览 2–3 行、标签、尺寸/模型（如有）、使用按钮。
- 点“使用”：把提示词写入当前画布输入框，应用保存的参数；**不自动提交生成**。
- 当前输入框已有内容时，提示“替换/取消”，避免误覆盖。

### 管理
- 编辑、删除、置顶、复制提示词。
- 导入/导出 JSON（备份/迁移），V1 可后置。
- 删除技能不影响画布任务/参考图。

## 2. 数据模型（V1）

```ts
type PromptSkill = {
  id: string
  title: string
  prompt: string
  tags: string[]
  category?: string
  params?: { size?: string; quality?: string; model?: string; n?: number }
  sourceTaskId?: string
  pinned?: boolean
  createdAt: number
  updatedAt: number
}
```

- 全局技能库，不绑定单个画布/项目。
- 存储：Tauri 用 SQLite kv（如 `panpan-prompt-skills-v1`），Web 用 localStorage；导出/导入走现有数据导出。
- 不存 API Key、不存绝对路径；参考图 V1 不存快照。

## 3. UI（借鉴 Google AI Studio + 卡片库）

- 入口：左侧第三个按钮“技能库”，点击在画布区域显示技能库视图（不是小弹窗）。
- 顶部：搜索框、分类/标签筛选、排序（最近/置顶/名称）、新建按钮。
- 主体：响应式卡片网格；卡片 hover 显示“使用/编辑/删除”。
- 空状态：说明 + “新建技能”/“从当前提示词保存”。
- 右侧/底部：提示词详情预览，避免卡片太长。
- 风格：延续盼盼工作台的玻璃/蓝色光晕，不要引入新的设计系统。

## 4. 关键边界

- 不做公开市场、账号、云同步、分享链接、付费。
- 不做 AI 自动生成提示词。
- 不复制 Google/PromptHero/FlowGPT 的代码或图片；只借鉴“搜索+标签+卡片+一键使用”的交互。
- 技能库的“使用”只改输入框/参数，不自动生成，不自动改参考图。
- 与参考图唯一数据源、生图后输入不变等已确认口径一致。

## 5. 开发顺序建议

1. 先完成当前已确认的 UI/交互修复（拖拽、参考图、删除默认、尺寸、下载、九宫格/About 等）。
2. 再做技能库 V1（数据 + 面板 + 保存/使用 + 测试）。
3. 最后做自动更新端到端、干净公开快照、安装/卸载验证。

原因：技能库要复用输入台、任务右键、参数应用；先把这些稳定下来，避免返工。

## 6. 已确认（按建议执行）

1. “使用技能”**替换**当前提示词；当前已有内容时先确认。
2. 从画布任务保存：V1 只保存提示词/参数，不保存参考图。
3. 技能库入口 = 左侧第三个按钮（现在恢复的“技能库”占位）。
4. V1 不做导入/导出 JSON；先本地保存，导出后续版本再做。
