## 6. 像素验收（补充，2026-11-17）

**行数 100% ≠ 像素 100%。** 文件一致但环境不同，留白仍会变。

### 前置三件事

1. **Token 对齐**：把原型 `index.css` 的间距/字号/圆角/阴影变量搬进 `studio.css`；
2. **字体对齐**：原型 Geist / Space Grotesk，本地 Noto 子集；不一致就补字体或确认度量；
3. **缺失工具类补齐**：Tailwind 4 有、Tailwind 3 没有的（`size-*`、部分 `space-y` 等），逐个补成普通 CSS。

### 判定

| 项 | 阈值 |
|---|---|
| 同尺寸截图差异像素 | **< 0.5%** |
| 结构 / class | 与原型一致（行数 ≥95% 已覆盖） |
| 图标尺寸与留白 | 肉眼与像素比对均无差异 |

### 六条全中才算 100%

1. 同一 DOM 结构
2. 同一套 class
3. 同一套 token
4. 同一套字体
5. 同一套图标尺寸
6. 并排截图差异 < 0.5%
---

## 7. 融合规则（覆盖第 6 节的 token / 字体对齐）

**不允许两套 UI 规范并存。** 原型提供版式，本项目提供皮肤。

| 层 | 听谁的 | 说明 |
|---|---|---|
| 几何：宽高、间距、圆角数值、图标尺寸、行高、列宽、层级 | **原型** | 决定"呼吸感"一致 |
| 视觉：颜色、字体族、字重、阴影色、深浅主题 | **本项目 `--studio-*` 与 `text-*` 阶梯** | 决定"像一个软件" |

### 禁止事项

- 不引入原型专有变量（`--color-*`、`--type-*`）；
- 不引入 Geist / Space Grotesk 等原型字体；
- 不新增第二套圆角/阴影/字号阶梯。

### 实现方式

保留原型 JSX 与几何 class；把其中的颜色/字体/阴影引用**替换为本项目 token**（映射表集中在 `studio.css`）。

### 验收（替代整图像素比对）

1. **几何比对**：同尺寸截图转灰度后比较，差异 **< 0.5%**；
2. **token 检查**：页面不存在原型专有变量或字体，全部解析到本项目 token；
3. 视觉验收由本项目既有页面做基准，不以原型颜色为准。
