## B. 节点设计定案（产品结论）

### B1. 节点数量：三个，不是四个

```
[ 素材 ]  →  [ 生成 ]  →  [ 结果 ]
```

| 原方案 | 改为 | 理由 |
|---|---|---|
| 加载图像 / 提示词 / 采样器 / 输出 | 素材 / 生成 / 结果 | 「提示词」和「采样器」拆开是给工程师看的；设计师的心智是「给图和话，出图」 |

### B2. 术语去技术化

| 不出现 | 用 |
|---|---|
| 采样器、VAE、CLIP、Checkpoint、LoRA、denoise | 模型、强度、张数、重绘幅度 |
| 电池、节点图、工作流执行图 | 步骤、流程 |

### B3. 三个节点各自的内容

**素材**
- 主图缩略图（拖入即选）
- 最多 3 张参考图（材质 / 风格 / 配景），横排缩略图
- 尺寸显示

**生成**
- 要求（正向提示词，多行）
- 排除（负向，默认折叠）
- 模型下拉（运行时从 `/object_info` 拉取，不写死）
- 强度：三档预设 `保结构 / 均衡 / 大胆改`，滑杆折叠进「高级」
- 张数：1 / 2 / 4
- 底部：进度 `12/20 · 预计 38s`，失败时红框 + 原因 + 重试

**结果**
- 单张：大图
- 多张：`2×2` 网格
- 底部两个动作：**对比原图**、**发送到画布**

### B4. 布局

- 三节点顶端对齐，水平从左到右
- 统一宽度 `280`，间距 `96`，坐标写死，**禁止自动布局**
- 打开时自适应全览（内容外扩 `40px`），不做固定 0.8
- 视口与参数按工作流 id 分别记忆

### B5. 与主画布一致的行为

- 点阵 + 聚光
- 缩放锚点、范围、步进
- 中键/空格平移
- 选中环 + 四角把手
- 主题切换
- 40% 以下隐藏节点内文字，只留标题与色条

---

## C. 验收口径

1. 工作流页与主画布并排截图，**看不出两套设计**
2. 缩放、平移、聚光手感一致
3. 三个节点在 1440 宽窗口内完整可见，无需横向滚动
4. 首次运行有加载态，不会白屏或假死
5. 失败时原因出现在「生成」节点内
6. 深浅主题各截一张

---

## D. 不做

- 通用节点编辑器
- 小地图、框选、多选、右键菜单
- 节点自由拖拽与连线编辑
- 子图、笔记节点
