## 3. 每页六项验收（缺一不算完）

1. **哈希**：页面组件文件与原型 sha256 相等；不相等就是被就地改过，直接红。
2. **零改动**：组件文件不在任何 patch 清单里；适配代码全部在 `adapters/**`。
3. **空控件扫描**：脚本遍历该页所有 `<button>`，无 `onClick` 且非 `disabled` → 红。
4. **构建与测试**：`npm run build` + `npm test` + 该页 E2E 全绿。
5. **总控亲手点**：每个按钮点一次，截图留证；不采信执行窗口自述。
6. **几何比对**：同尺寸截图转灰度，布局差异 **< 0.5%**（只判结构与留白，不判颜色）。

颜色与字体按 `ACCEPTANCE-20261117.md` 第 7 节：视觉用本项目 token，几何照原型。

- 同一处连续失败两次 → 停，换路线，不试第三种写法；
- 每个决定先写 ADR，再改代码，提交信息引用 ADR 编号。
