- 允许删除所有项目/画布，包括默认项目/默认画布。
- 删除当前项后切到剩余项；没有则显示“新建项目/新建画布”空状态。

- 删除前确认 + 含图片 ZIP 快照，可恢复。

## 4. 参考图命名

- 统一用 `图1`、`图2`（与原型一致）。
- 输入框、参考图架、画布图片节点三处编号一致。
- 移动/排序后自动重编号。

## 5. 字体打包

- 不再依赖 `fontsapi.zeoseven.com` / `cdn.jsdelivr.net` 外部字体。
- 把所需字体打包进安装包；离线可用、隐私更好；接受安装包变大。
- 更新 CSP，移除外部字体域名。

## 6. MCP 写工具（解释 + 待定）

- 只读工具：列出项目/画布/任务/设置/图片，不会改数据。
- 写工具：`task.create`（创建生成任务）、`image.attach`（把图片加入当前参考图）。
- 写工具默认关闭；即使打开，每次调用也会在主窗口弹确认框，用户点确认才执行；执行复用现有 `submitTask`/`addInputImage`。
- 不是后台偷偷改数据，也不是外部网络可直接调用；只绑 127.0.0.1 + token。
- 选择：**A. 保留写工具，默认关闭 + UI 确认**（用户已确认）。
- 公开发布版仍默认关闭；README 说明本地 token、端口、写入确认。
