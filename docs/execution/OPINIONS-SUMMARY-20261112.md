## 0. 一条主线

按你的原型逻辑，页面职责重新收口为：

```text
左侧栏 = 项目层
  ├─ 搜索项目
  ├─ 折叠/展开侧栏
  ├─ 项目列表（平铺，不折叠）
  └─ 新建项目（底部）

画布顶部胶囊 = 画布层
  ├─ 切换当前项目的不同画布
  ├─ 新建画布
  ├─ 双击重命名
  ├─ 右键：重命名 / 复制 / 删除
  └─ 溢出滚动 / 最后一个画布保护

输入框 = 生成层
  ├─ 提示词、参考图、技能
  ├─ 模型/尺寸/数量/质量
  └─ 右下角：卡片视图切换

卡片视图头部 = 管理/筛选层
  ├─ 搜索/筛选
  ├─ 多选/批量
  └─ 排序
```

一句话：**每个区域只做一件事；设置类进设置，导航类进侧栏，画布类进顶部胶囊，生成类进输入框。**

## 2. 我建议保留的补充点（你已同意保留）

这些已包含在 N38/N40/N50/N52 里，归纳时单列，避免实现时漏掉：

1. **搜索/筛选落位**：搜索放侧栏头部；筛选和排序放卡片视图头部；不再常驻画布顶部。
2. **多选回归框选 + Ctrl/Cmd+A**：不再保留常驻“多选”按钮。
3. **批量操作只在选中后出现**：不占用常驻工具条。
4. **新建后直接进入命名态**：不只支持双击改名。
5. **最后一个画布不可删**：删当前画布自动切相邻。
6. **胶囊溢出**：不再 `slice(0, 6)`，改为横向滚动 + 两侧渐隐/箭头。
7. **重命名三处同步**：侧栏、顶部胶囊、窗口标题/详情一致。
8. **项目删除与画布删除分开**：项目删除影响多画布，必须确认；画布删除只影响当前。
9. **按钮契约测试**：每个按钮必须有点击结果、禁用原因、至少一条 E2E 或单测覆盖。
10. **清理旧 CanvasWorkbench 死按钮**，避免再次出现“假按钮”。
11. **保存/导出单一契约**：格式设置 → 实际 MIME → 文件名扩展名 → 对话框默认名/过滤器 → 保存后补扩展名。
12. **撤销改成命令栈**：不再只做位置快照；覆盖移动、缩放、对齐、排列、删除。
