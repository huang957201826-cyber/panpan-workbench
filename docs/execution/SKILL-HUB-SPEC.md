# 技能库目标规格（Skill Hub Spec）

- 日期：2026-11-07
- 依据：你提供的 Google AI Studio 技能库截图（`artifacts/user-04-skillhub-ref.jpg`）+ 参考源码 `SkillHubView.tsx`
- 状态：**目标规格，未落代码**
- 一句话：现在的技能库是"能用的列表"，目标是"可浏览的配方陈列馆"——三栏结构、封面卡、分类即筛选、一键调用。

---

## 1. 目标结构（三栏）

```
┌────┬──────────────────┬──────────────────────────────────────────────┐
│ 56 │ 232 技能与配方    │  顶栏 48：分类 Tab（带计数）  搜索  模型筛选   │
│rail│                  ├──────────────────────────────────────────────┤
│    │ 一键调用说明卡    │  3 列卡片网格 gap 16                         │
│    │ 精选空间分类(4)   │  ┌────────┐ ┌────────┐ ┌────────┐            │
│    │ 热门标签(6)       │  │ 16:9 封面│ │        │ │        │            │
│    │                  │  │ 标题/描述│ │        │ │        │            │
│    │                  │  │ 复制|调用│ │        │ │        │            │
│    │ …                │  └────────┘ └────────┘ └────────┘            │
└────┴──────────────────┴──────────────────────────────────────────────┘
```

与现在最大的差别：**技能库要占满主区并自带左右两栏**，不再是"画布区域里的一块列表"。

---

## 2. 左侧面板（232px，与"工作区方案"面板同宽同规格）

| 区块 | 规格 |
|---|---|
| 面板头（44px） | `技能与配方` + `Hub` 小徽章 + 右侧 `7 条` 计数；下边线 `--border` |
| 说明卡 | 圆角 12、`--surface-2` 底、内边距 12；标题 `一键调用说明`（12/600）；正文 11.5/1.6 `--text-2`：**"点击「一键调用」，把这条配方的提示词与参数直接注入当前工作区底栏。"** |
| 精选空间分类 | 小标题 11/600 `--text-3`；列表项：图标 14 + 名称 12.5 + 右侧 `2 条`（11 mono `--text-3`）；行高 32、圆角 8；**选中行**用 `--brand-soft` 底 + `--brand` 文字 |
| 热门标签 | 小标题同上；标签用 chip（高 24、圆角 6、11px），超过 2 行折叠成"+N" |
| 底部 | `…` 更多（导入/导出技能，后续） |

> 左侧分类 = 主筛选轴（空间/题材）；顶部 Tab = 次筛选轴（风格类型）。两者可叠加，互不清空。

---

## 3. 顶栏（48px，sticky，不浮动）

- 左：**分类 Tab 组**（分段控件，选中=实心黑/深色实心白），每项 `名称 (数量)`，计数用 mono 10.5 `--text-3`；超出宽度横向滚动（隐藏滚动条，hover 显示）。
- 右：搜索框（宽 200，聚焦展开到 240，前置 Search 图标 14，占位"搜索配方与关键词…"）+ 模型筛选（自绘 Select，宽 120，占位"通用底模"）。
- 右侧可留一个 `新建技能` 主按钮（参考截图没有，但我们需要入口；放在最右，实心黑 28px 高）。

---

## 4. 卡片（核心）

**尺寸**：3 列（≥1280）/ 2 列（≥1024）/ 1 列（<1024）；gap 16；卡片圆角 12、`--surface` 底、`--border` 1px；hover 升 `e2` + 描边加深 + 封面 `scale(1.02)`。

**封面（16:9）**
| 位置 | 内容 | 规格 |
|---|---|---|
| 左上 | 分类徽章（商业空间 / 光影镜头 / 材质质感 / 负向增强 / 艺术风格） | 高 20、圆角 6、`bg-black/60` + blur、白字 10.5 |
| 右上 | 收藏星 | 32×32 命中区、图标 16；已收藏=金色实心，未收藏=白 70% 描边 |
| 左下 | 推荐模型（`GPT-Image-2.5 / FLUX.1-Dev`） | mono 10.5、白 90% |
| 右下 | 参数槽数量（`2 参数槽`） | mono 10.5、白 60% |
| 底部渐变 | `black/75 → transparent` 40% 高 | 保证文字可读 |

**正文（padding 12）**
- 标题：13/600 `--text-1`，单行省略。
- 描述：12/1.5 `--text-2`，**2 行截断**（`line-clamp-2`）。
- 标签：`#` 前缀 chip，最多 3 个，超出忽略；11px、`--surface-2` 底。

**底部动作条（padding 12，上边线）**
- 左：`复制配方`（Copy 图标 14 + 11px 文字，幽灵按钮，点击后变"已复制"并对勾 1.8s）。
- 右：`一键调用`（实心胶囊 28 高，Zap 图标 14 + 文字 11.5/500），点击前若当前提示词非空 → 二次确认。

**无封面时的兜底**：按 `skill.id` 生成确定性双色渐变 + 点阵纹理（同一条技能永远同一张），避免新库一片灰块。

## 5. 详情弹窗（点卡片打开）

- 尺寸：`max-width 720`，`max-height 80vh`，圆角 16。
- 头部 44：分类徽章 + 标题 + 关闭按钮。
- 左栏：封面 16:9 + 设计说明 + 元信息（推荐底模 / 参数槽数 / 作者）。
- 右栏：参数槽（每个变量一个输入或下拉，实时合成）+ 合成后的完整提示词（可复制，最大高 144 滚动）。
- 底部：`关闭` / `注入到当前工作区`（主按钮）。
- 负向提示词单独一块（红色系 3% 底 + 红边），只在有值时显示。

## 7. 数据模型缺口（现在没有，必须扩）

现在的 `PromptSkill`（`src/types.ts:307`）只有：`id / title / prompt / tags / category? / params? / sourceTaskId? / pinned? / createdAt / updatedAt`。

要支撑截图上的版式，需要补：

| 字段 | 类型 | 用途 | 兼容策略 |
|---|---|---|---|
| `coverImageId` | `string?` | 封面用本地图片（从任务保存时抓输出图） | 旧数据无 → 走渐变兜底 |
| `favorite` | `boolean?` | 收藏（与 `pinned` 语义分开：置顶=排序，收藏=筛选） | 缺省 false |
| `variables` | `{key,label,defaultValue,options?}[]` | 参数槽（`{{主体}}` 占位符） | 缺省空数组 |
| `negativePrompt` | `string?` | 负向提示词 | 缺省空 |
| `usageCount` | `number?` | 使用次数（排序/热度） | 缺省 0 |
| `author` | `string?` | 作者（参考截图右下有作者名） | 缺省"本地" |
| `category` | 枚举 | 现在自由文本，需要固定成 5–8 个可选项 | 旧值归入"其他" |

**注意**：`variables` 与 `negativePrompt` 不只影响技能库——生成链路里也**没有负向提示词字段**（全项目 grep 无 `negative`），要确认是否作为独立参数透传给供应商，还是仅拼进 prompt 尾部。

## 8. 现状 vs 目标（差距表）

| 项 | 现在 | 目标 |
|---|---|---|
| 结构 | 单栏：标题行 + 卡片网格 | 三栏：rail + 分类面板 + 顶栏 + 网格 |
| 顶栏 | 一行 flex-wrap：标题 + 搜索 + 3 个原生 select + 新建 | 48px：分类 Tab（带计数）+ 搜索 + 模型筛选 + 新建 |
| 卡片 | 纯文字，`min-h 170`，无封面 | 16:9 封面 + 四角信息 + 标题/描述/标签 + 底部双动作 |
| 分类 | 原生下拉 | 左侧列表（带计数）+ 顶部 Tab（带计数）双轴 |
| 模型筛选 | 无 | 有 |
| 收藏 | 只有"置顶" | 收藏星（筛选）+ 置顶（排序）分离 |
| 复制 | 无 | 有（含"已复制"反馈） |
| 详情 | 扁平编辑表单 | 双栏 Inspector（封面 + 参数槽 + 实时合成提示词） |
| 空/加载态 | 有空态，无骨架 | 空态 + 骨架 + 无匹配三态 |

## 9. 验收标准

1. 1280 宽下是 3 列，1024 下 2 列，960 下 1 列，卡片不裁切、不溢出。
2. 顶栏在滚动时固定（sticky），左面板独立滚动。
3. 每张卡都能看到：分类、封面、模型、参数槽数、标题、2 行描述、标签、两个动作。
4. 收藏星点击不触发卡片打开（`stopPropagation`）。
5. "一键调用"在提示词非空时弹确认；确认后替换提示词与参数、**不自动提交**。
6. 无封面的旧技能显示确定性渐变，不出现空白灰块。
7. 三态（空/无匹配/加载）齐全。
8. 深浅主题都过一遍截图。
