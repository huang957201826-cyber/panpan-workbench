## 二、缺的不是功能，是闭环

统计：**通 18 项、断 5 项、缺 1 项、待点 3 项**。
断点集中在两类：

1. **数据写回**：项目历史、下载产物；
2. **跨入口一致性**：技能两套数据、三处左栏规格。

## 三、收藏计数为什么错位

- 「收藏」不是真实项目，是 `favorites.ts` 注入的合成行（`__favorites__`），渲染在同一列表里；
- 但整行仍是旧规格：`h-[42px]`、`text-[12.5px]`、`rounded-xl`、`px-2.5`，**没有参与 1.6.0 的字号统一**；
- 计数在 `justify-between` 的右侧，但收藏行左侧是星标 + 文本，和文件夹行的图标宽度不同，视觉上右边计数就像"少了一格"；
- 根因不是右边缺菜单，是**这行没进统一规格**。

## 四、测试缺口

- 单测 1137 条，覆盖 store / lib / 部分组件；
- **没有**覆盖新三页的 E2E：设置页签、技能新建/持久化、工作流项目保存与下载；
- 验收一直是"人工点"，没有自动化回归。

建议补三条 E2E（Playwright 已有基建）：
1. 设置：打开 → 切 5 页签 → 关闭；
2. 技能：新建 → 刷新 → 仍在 → 删除；
3. 工作流：新建项目 → 保存 → 刷新 → 项目与记录仍在。
