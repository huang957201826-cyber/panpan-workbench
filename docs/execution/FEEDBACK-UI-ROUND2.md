## 1. 生成中 / 生成错误的画布状态

- **生成中**：
  - 画布节点显示模糊占位图，逐渐变清晰（blur-up 出现）。
  - 背景/占位虚化，显示“生成中”和计时（如 `00:12`）。
  - 目的：无限画布图片多时，一眼能看出哪些在生成、生成多久。
- **生成错误**：
  - 直接在图片画框上画一个明显的叉（X），不要只显示“失败”小标签。
  - 保留错误信息入口（悬停/点击查看）和重试入口。
- 现状：
  - `CanvasTaskNode.tsx` 固定 360×280/280×150，running 只显示文字，error 只有红色小标签；
  - 没有模糊占位、没有计时、没有整图 X。
- 实现注意：
  - API 只返回最终图，无法拿到真实逐步像素；用“模糊骨架 → 完成时 blur-up 揭示”模拟，不伪造进度百分比。
  - 计时用任务 startedAt/createdAt 计算，mm:ss；完成后停止。
  - X 不要遮住“重试/详情”按钮；错误节点仍可点开详情。

## 2. 画布缩略图还原真实比例

- 节点宽高应按 `task.params.size` / 图片自然比例计算，不再固定 360×280。
- 生成中/错误没有最终图时，用请求的 size/比例做占位框。
- 现状：`CanvasTaskNode` 使用固定宽高 + `object-cover`，会裁切。

## 3. 画布鼠标蓝色动效（Google AI Studio 风格）

- 鼠标在无限画布上移动时，显示蓝色光晕/圆点/聚光效果，快速定位鼠标位置。
- 鼠标位置的点/环要有跟随动效，离开画布淡出；不要遮挡点击/框选/拖拽。
- 现状：已找到原型实现，当前 `CanvasBoard` 没有接回来。
  - `src/studio/components/InfiniteCanvas.tsx:51` `glowRef`
  - `InfiniteCanvas.tsx:143-151` `handleMouseMove` 写入 `--mx/--my`
  - `InfiniteCanvas.tsx:277-281` `stitch-dot-highlight` 层
  - `src/studio/studio.css:75-89` 用 `radial-gradient` + mask 做 140px 指针聚光
  - 这套原型是“点阵聚光”，CSS 里当前是深色/白色点，不是蓝色；Git 历史里没有找到蓝色版本。
  - 当前 `CanvasBoard.tsx` 自己画了 `stitch-dot-canvas`，但没有 `stitch-dot-highlight`，所以效果丢了。
- 实现口径：直接复用 `InfiniteCanvas` 的 `glowRef` + `--mx/--my` + `stitch-dot-highlight` 机制，移植到 `CanvasBoard`；不重新发明。按用户要求加蓝色光标点/光晕（在原型点阵聚光基础上加蓝色层），保留原有点阵效果。

## 4. @ 参考图高亮与自动改号

- 输入 `@` 或选中参考图时，`@图N` 要变成蓝色（原型就是这样），不要只是普通文字。
- 参考图位置移动/排序后，`@图N` 自动重编号（如 @图1 → @图2），图片名称/编号也跟着变。
- 现状：
  - `BottomPromptBar.tsx` 里 `@图N` 是纯文本插入，没有蓝色 capsule；
  - `promptImageMentions.ts` 有 `remapImageMentionsForOrder`，但 Studio 输入台没有完整使用。
- 实现注意：
  - mention 用不可编辑的蓝色 chip（或等宽高亮），保留光标位置/键盘删除；
  - 排序、拖入、删除参考图后统一调用 remap，输入框、参考图架、画布图片节点三处编号一致；
  - 颜色不是唯一提示，保留下划线/编号，避免无障碍问题。

## 我建议一并考虑的类似优化（待用户确认）

1. 生成中节点：蓝色呼吸边框 + 计时；完成时 300–500ms blur-up，不要突然弹出。
2. 错误节点：整图红色半透明遮罩 + 大 X + 悬停显示错误摘要；点击 X 不触发详情，点其他区域打开详情。
3. 比例：节点尺寸按 `size` 比例计算，设最小 160px、最大 480px；长图用 `object-contain` + 棋盘/深色底。
4. 鼠标光效：蓝色 radial glow + 小圆点，移动时轻微拖尾；点击/框选时淡出，避免干扰。
5. @ 编号：参考图架显示蓝色 `@图N` 徽标；拖动排序时实时预览新编号；输入框内 mention 同步变蓝。
6. 画布图片节点显示文件名/编号（如 `图1`），hover 出现“设为参考图/下载/删除”，与输入框编号一致。
7. 统一状态色：生成中蓝、成功绿、失败红；不要只靠颜色，配图标/文字。
8. 计时只在 running 时刷新，完成后冻结；避免多个节点定时器过多（共享一个 tick）。
