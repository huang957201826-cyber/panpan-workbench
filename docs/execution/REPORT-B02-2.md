## 复审阻塞修复

1. 拖拽/拾取等待入库
   - 画布文件拖入改为等待 `Promise.all(addImageFromFile)`，全部真正加入参考图后才记录落点；部分失败提示并取消落点。
   - 画布图片拖入/拾取改为等待 `ensureImageCached` 与 `addInputImage` 完成；成功后才提示和退出拾取态。
   - 加入参考图期间标记 pending，输入台提交被禁用并在 `handleGenerate` 再次拦截，避免迟到图片进入下一次任务。
   - 新增测试：`addImageFromFile` 后立即提交的 `inputImageIds` 包含新图；非图片文件不提示成功。

2. stop 后排队任务不再执行
   - `stopTask`、删除任务、清空任务、覆盖重试时从 `manualTaskQueue` 移除对应 ID。
   - `executeTask` 取到任务后先检查 `status === 'running'`，并用现有 execution token 继续校验，已停止的排队任务不会调用 API。
   - 新增测试：并发 1 下提交 A/B，停止 B 后 A 完成，B 保持 error，API 只调用一次。

3. 批量停止保留未提交输入
   - `runBatchPrompts` 停止时返回未启动条目，并按原顺序计算保留列表。
   - `submitTask` 在存在未启动或失败条目时保留提示词与参考图；全部成功才按设置清空。
   - 新增测试：三条批量启动一条后停止，保留剩余两条与参考图；全部成功仍清空输入。
