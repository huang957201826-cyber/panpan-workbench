
## 追加 4 条（2026-11-07，待实现）

### A. 选中图片右上角直接下载

- 现状：需要双击打开详情后才能下载，不方便。
- 需求：选中图片/任务节点后，右上角出现下载按钮，一键下载；不要必须打开详情。
- 范围：无限画布任务节点、九宫格卡片、图片节点都应支持；多输出任务可点一次下载当前图，或小菜单选择第几张。
- 保留双击打开详情；下载按钮不要和“选中/拖动/右键菜单”冲突。
- 交互：hover 出现、选中常驻；tooltip“下载原图”；下载中显示进度/禁用，失败提示。

### B. 画布底部黑色 hover 效果改高级

- 现状：鼠标悬停到无限画布底部时出现的黑色悬浮效果不好看。
- 需求：改成更高级的效果，旁边带蓝色光晕（类似参考图的感觉），不要纯黑块。
- 待确认：具体是底部哪一条（悬浮工具栏/黑色按钮/黑色提示条）；实现前用截图确认。
- 方向：玻璃拟态/半透明深色底 + 蓝色柔和光晕/描边，圆角、轻阴影；hover/选中时蓝光增强，不遮挡内容。
- 不影响点击、拖拽、缩放；亮暗主题都适配。

### C. 默认项目/默认画布允许删除

- 现状：有一个默认画布删不掉，很难受。
- 需求：允许删除所有项目/画布，包括默认项目、默认画布。
- 删除后的行为：
  - 删除当前画布：切到剩余画布；没有则显示空状态“新建画布”。
  - 删除当前项目：切到剩余项目；没有则显示空状态“新建项目”。
  - 不自动偷偷重建默认项目/画布；只有用户新建或首次启动无数据时才创建默认。
  - 删除前仍走确认 + 含图片的 ZIP 快照；可恢复。
- 需要检查：workspace 规范化、`defaultCanvasId`/`default-project` 特殊保护、删除快照、MCP/画布切换。

### D. 尺寸预设改为 1K/2K 16:9、1K 9:16

- 现状：`STUDIO_SIZE_OPTIONS` 是 自动 / 1:1 1024×1024 / 3:2 1536×1024 / 2:3 1024×1536。
- 需求：
  - 1K 16:9 = **1280×720**
  - 1K 9:16 = **720×1280**
  - 2K 16:9 = **2560×1440**
- 建议保留“自动”作为第四项（不选像素，由模型决定）；如果用户要求只留三项，再去掉自动。
- 标签显示比例 + 像素，如 `1K 16:9 · 1280×720`；画布节点按该比例显示。
- 需要验证 gpt-image-2.5 实际支持这些尺寸；不支持时回退到最近支持尺寸并提示，不静默改。
- 旧任务/旧画布保持原尺寸，不迁移。
