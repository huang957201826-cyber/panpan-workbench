## 1. 画布右下角控件与输入台错位

### 现象

缩放百分比 + 全览按钮位于输入台下方，视觉上"掉"到输入台底下，而不是与输入台齐平。

### 根因（代码事实）

| 元素 | 定位 | 实际位置 |
|---|---|---|
| 输入台外层 | `StudioShell.tsx` `absolute bottom-16` | 距画布底 **64px** |
| 画布控件胶囊 | `InfiniteCanvas.tsx` `absolute bottom-3` | 距画布底 **12px** |

两者相差 52px，所以控件在输入台**下方**。这不是视觉微调问题，是**用了两套互不相干的定位基准**。

另外 `StudioShell` 已经算出了 `--input-bar-clearance = 输入台高度 + 64px`，用于画布内容避让，但控件胶囊没有使用它。

### 应遵守的规则

**画布上的浮动控件，基线必须由输入台的同一个变量推导，不允许写死。**

具体：
- 控件底边 = 输入台底边（64px），两者齐平；
- 控件右边 = 输入台右边（同一 `max-w` 与内边距）；
- 输入台切到右侧停靠时，控件要么跟随，要么隐藏，不能重叠。

## 2. API 配置的入门流程

### 现状

设置 → API 里有：配置名称、Base URL、API Key、模型、测试连接、导入/导出、预置服务商。

对小白的问题：
1. **URL 是技术噪音**，但被放在和密钥同等重要的位置；
2. **模型要手打**，打错就报错，且不知道有哪些可选；
3. **"测试连接"是用户动作**，本应自动；
4. **预置服务商和用户自己的配置混在一个列表里**，广告和私钥混在一起，认知混乱；
5. 「优化名称」语义不清，用户不知道点了会发生什么。

### 成熟做法（可对标的模式）

| 产品 | 做法 |
|---|---|
| OpenRouter | 一个 endpoint + 一个 key；模型列表由 `GET /api/v1/models` 拉取，从真实列表选，不手打 |
| OpenAI 平台 | 创建 key 后直接粘贴；Base URL 不需要用户填 |
| Chatbox / Cherry Studio 类 | 「添加服务商」→ 选厂商（Logo 卡片）→ 自动填 URL → 粘 key → 自动拉模型 |
| 各类 BYOK 工具 | 按 key 前缀识别厂商（`sk-` → OpenAI 兼容，`AIza` → Google） |

共同点：**能推断的绝不问用户；能自动的绝不做成按钮。**

### 建议流程（3 步，不是 5 步）

**第 1 步 · 选来源**（一个弹窗，三张卡）

| 卡片 | 说明 |
|---|---|
| 我有密钥 | 主入口，占最大面积 |
| 从推荐服务商添加 | 明确标注「含返利」，默认不选，不写入配置 |
| 导入配置码 | 老用户/换机迁移 |

**第 2 步 · 粘贴密钥**
- 只有一个输入框：API Key
- 粘贴后自动识别厂商并预填 URL
- URL 收进「高级」，默认不展开
- **自动测通**（后台执行），结果以状态行显示，不要"测试连接"按钮

**第 3 步 · 选模型**
- 自动请求 `/v1/models`，下拉选择（显示价格/能力标签）
- 保存时自动命名：`服务商 · 模型`，可改

为什么砍掉两步：URL 对小白是噪音；测试不该是用户的动作；模型名不该手打。

### 广告位与密钥必须物理隔离

问题：预置中转站（含返利参数）如果作为"配置"出现在列表里，会和用户自己的密钥混在一起。

规则：
1. **预置服务商永远不进入「我的配置」列表**，单独一块区域；
2. 推荐卡上明确写「含返利」，这是信任问题不是文案问题；
3. 点「使用」时**新建一条用户配置**（key 为空、name 自动），而不是把预置对象塞进列表；
4. 预置项永远不带 key，UI 上要说明"需要你自己注册获取"。

## 3. 命名与入口

| 现状 | 建议 |
|---|---|
| 「优化名称」 | **删除**。改为保存时自动命名，用户可改 |
| 列表混排预置与自建 | 拆成「我的配置」「推荐服务商」两块 |
| 添加入口不明确 | 统一为「添加 API 配置」，进入后三选一（见上） |

自动命名规则：`<服务商> · <模型>`，重名追加序号。用户手动改过就不再覆盖。

## 4. 已确认（2026-11-15，用户拍板）

### 4.1 缩放按钮：底边对齐，允许被输入台盖住

- 对齐方式：**底边对齐**（按钮底边与输入台底边同一条线）。
- 空间不够时：**输入台可以盖住按钮**，按钮不躲、不位移。
  - 层级：输入台 `z-index` 高于画布控件；
  - 按钮保持右下角的位置，被覆盖即被覆盖；
  - 不做"自动躲到别处"的动效，避免控件跳来跳去。

### 4.2 配置 API：三步向导

1. 选来源（我有密钥 / 推荐服务商 / 导入配置码）
2. 粘贴密钥（自动识别厂商、自动填 URL、自动测通）
3. 选模型（从 `/v1/models` 真实列表选）

同一个弹窗内分屏，不是新页面。

### 4.3 推荐服务商：保留，但隔离

- 保留 `api.tehui.xyz` 预置，方便新用户拿到密钥；
- 必须与「我的配置」物理分离，独立区域；
- 卡片上明示「含返利」；
- 点「使用」后**新建一条用户自己的配置**（key 为空、名字自动），不把预置对象塞进配置列表；
- 预置项永远不带 key。
