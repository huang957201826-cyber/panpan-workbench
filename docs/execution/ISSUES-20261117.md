# 问题记录（2026-11-17）

> 规则：先记录，不改代码；每条要有现象、证据、原因判断、状态。

## P-01 窗口像是"强制置顶"

- **现象**：应用窗口一直压在其他窗口上方，切走也不下沉。
- **证据**：`src-tauri/tauri.conf.json` 没有 `alwaysOnTop`；当前窗口扩展样式 `WS_EX_TOPMOST = false`。
- **原因判断**：不是产品行为。是我在截图/验收时用自动化脚本调用 `SetWindowPos(HWND_TOPMOST)` 造成的；应用重启后已恢复。
- **风险**：只要我再跑截图脚本，就可能再次出现。
- **约定**：自动化截图结束后必须显式取消置顶（`HWND_NOTOPMOST`）；不要用 `HWND_TOPMOST` 做"保证可见"的手段。
- **状态**：已记录，无需改产品代码。

## P-02 工作流画布拖拽卡顿

- **现象**：移动节点、拖分组框明显掉帧。
- **证据（代码定位）**：
  1. `ComfyWorkflowView.tsx` 432–443：`pointermove` 内直接 `setNodes`，每次移动重渲染 2386 行组件；
  2. 节点未 memo 化；
  3. 同文件 11 处 `backdrop-blur`；
  4. `InteractiveDotGrid` 常驻 60fps 动画。
- **原因判断**：拖拽路径写 React state + 全量重渲染 + 高成本模糊合成。
- **计划**：1.6.2 用 transform 拖拽 + 松手落位、节点 memo、拖拽时暂停点阵与模糊；改前后各测 3 秒帧间隔（平均 ≤16.7ms、最差 ≤33ms）。
- **状态**：处理中（1.6.2）。

## P-03 局部重绘 / 截图转效果图 缺界面取证

- **现象**：两条 qwen 流程可用，但没有"界面出图"截图。
- **证据**：引擎侧 `execution_success`，su-render 947.1s，写入 `su-render_*.png`；应用在截图前被重启。
- **原因判断**：单次 15 分钟 + 安装重启打断，不是功能不通。
- **状态**：known-limit，待一次完整运行补证。
