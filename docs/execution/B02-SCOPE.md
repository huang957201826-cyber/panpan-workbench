## B02-3 托盘、品牌与显示（不做复杂系统）

1. **关闭到托盘**
   - 点窗口关闭 = 隐藏到系统托盘，不退出。
   - 托盘图标：显示主窗口 / 退出。
   - 不做开机启动、不做复杂托盘菜单（除非后续明确要求）。
2. **界面尺度与 DPI**
   - 设置 → 外观增加“界面缩放：跟随系统 / 100 / 110 / 125 / 150%”，只缩放 UI chrome，不缩放画布世界坐标。
   - 字号阶梯：正文 13px、次要 12px、标签 11px 下限；清理 9–10px 正文，改用 rem + 根字号缩放。
   - 实现方式：UI 的 arbitrary px（`text-[Npx]`、`h-[26px]` 等）改 rem/Tailwind 标度，`html` 根字号 = `16px × 界面缩放`；画布世界坐标继续用 px。不要用 CSS `zoom` 整体缩放，否则画布/图片会一起变。
   - 微放大映射：`9/9.5→11.5/12`、`10/10.5→12`、`11→12.5`、`11.5→13`、`12→13.5`；`8/8.5` 只留角标且不小于 10。
   - 图标：`12→14`、`14→16`、`16→18`、主工具栏 `20→22`；图标按钮点击区 `24→30–32`，触屏目标 44。
   - 留白：卡片 padding `10→12`，密集行 `6→8`，组间 `8→10/12`，胶囊高度 `26→30`；保留 4px 网格但不要全用 4px。
   - 对比度/焦点：9–10px 的 `text-slate-400` 按 4.5:1 复核；补 `focus-visible`；禁用态不要只靠 opacity。
   - 默认窗口按工作区约 80% 打开（上限 1440×920，下限 960×640）；恢复窗口状态时校验是否在当前显示器内，越界则居中。
   - 大屏断点：≥1600px 放大侧栏/抽屉/输入台上限；最小窗口 800→960，或 <960 强制抽屉浮层。
   - 字体统一：打包 Geist/Space Grotesk/JetBrains Mono，或 Studio 复用 `--font-ui-sans`；不写不存在的字体名。
   - Web/PWA 允许缩放，去掉 `user-scalable=no`。
   - 验证矩阵：1080P@100/125、2K@100/150、4K@150/200、800×600、混合 DPI 双屏。
3. **C 品牌全套**
   - 以 `C · 折角入口` 为唯一 master，生成窗口、任务栏、桌面、开始菜单、安装器、卸载器、favicon、PWA 192/512 PNG、32px 简化版。
   - AppLogo、标题栏、侧栏统一用 C；不再使用几何准星/熊猫混搭。
4. **用户可见命名**
   - 统一“盼盼工作台”显示名、发布者、快捷方式名、安装器显示名。
   - 不重命名 exe/内部协议/包名，避免破坏旧数据、旧快捷方式和兼容性；只清理用户可见文案和安装入口。
5. **安装清理**

   - PWA 补 PNG 图标。
6. **安全与上游清理**
   - 配置导入改为显式动作：不再每次窗口聚焦自动读剪贴板；导入前显示目标 host，非 HTTPS/未知 host 必须二次确认；不再接受任意 `apiUrl/apiKey` 静默覆盖。
   - `src-tauri/.env` 的 `VITE_WEB_APP_URL` 改为自有域名或空；删掉 `cooksleep.dev` 测试残留。
   - `RELEASE.md` 改为本 fork 的版本记录；`.github/workflows` 的 deploy/docker/release/vercel 改为自有仓库或停用；Header 上游 Releases 链接、`api.github.com` CSP、无效的 `autoCheckUpdate` 开关一并清掉。

## B02-4 MCP（本次必须交付，不再后置）

1. **本机 MCP Server**
   - 只监听 `127.0.0.1`，默认关闭；设置里可开启、设端口、生成/复制 token。
   - 提供 Streamable HTTP MCP 端点 + stdio 桥接，兼容 Claude Desktop/Cursor 等客户端。
   - 用官方 `rmcp` Rust SDK（MIT）实现，不手写 JSON-RPC；同一个 exe 加 `--mcp-stdio` 走 stdio，不额外依赖 Node。
   - 端口固定可配（默认如 `39271`），被占用时明确报错并允许改端口，不静默换端口。
2. **只读工具（第一批）**
   - `project.list`、`canvas.list`、`task.list`、`task.get`、`image.get`（元数据/缩略图）、`settings.get`（脱敏）。
   - 不返回 API Key、不返回绝对敏感路径。
3. **写入工具（同一批，二次确认）**
   - `task.create`、`image.attach` 等默认关闭；开启时每次操作需确认。
   - 只复用现有 `submitTask`/图片库，不新建第二套生成链路。
4. **设置页**
   - MCP 开关、端口、token、复制客户端配置、最近调用日志；默认不开。
5. **安全/测试**
   - token 至少 32 字节随机；只走 `Authorization: Bearer`，不进 URL/日志；常数时间比较；支持轮换/撤销。
   - 只监听 `127.0.0.1`；校验 `Host` 必须是 `127.0.0.1:端口`/`localhost:端口`；拒绝任意 `Origin`，不返回 CORS 头，防 DNS rebinding/浏览器跨站调用。
   - 工具输出分页（默认 50、最大 100）和大小上限；`image.get` 只返回缩略图/base64 或临时 URL，不返回绝对路径；`settings.get` 只返回白名单字段。
   - 写入工具默认关闭；每次调用弹 UI 确认（摘要 + 超时 60 秒）；没有 UI/无人确认时拒绝，不静默执行。
   - 限流（如 60 次/分钟）、审计日志（时间/工具/结果/耗时），日志脱敏，不记录 Key、token、图片内容。
   - 测试：未授权/错 token/非本机 Host/带 Origin 全部拒绝；只读工具可用；响应无 API Key/绝对路径；写入必须确认；端口占用可恢复；审计日志无敏感信息。
