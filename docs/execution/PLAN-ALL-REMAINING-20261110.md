### 13.2 R2 实体与生命周期契约（冻结）

- **侧栏 = 项目层**：平铺项目，不显示画布树、不显示折叠箭头；点击项目恢复该项目上次画布，没有则取第一个画布。
  - “项目上次画布”放 `StudioShell` 内存 Map（projectId → canvasId），不新增持久化字段；重启回落项目第一个画布。
- **侧栏底部 = 新建项目**；顶部“新建创作方案”移除。
- **胶囊 = 画布层**：只显示当前项目画布；`+` 新建画布后直接进入命名态。
- **删除画布**：统一走 `deleteCanvas(move/delete)` 的任务迁移/删除确认；最后 1 个画布在 action 层拒绝删除；删除当前画布后切相邻画布，不跳第一个。
- **胶囊溢出**：去掉 `slice(0, 6)`，横向滚动 + 渐隐/箭头。
- **重命名同步**：胶囊、画布标题、详情标题同步；侧栏不再显示画布名，不做“三处同步”。
- **项目删除**：仍走项目确认；删除项目后若没有项目，创建默认项目/画布，不能留下空工作区。

### 13.3 R1 撤销契约（冻结）

- 单一按 `canvasId` 的异步命令栈，最多 20 步；`canUndo` 按当前 `activeCanvasId` 对应栈计算，切换/删除画布时丢弃该 `canvasId` 的栈，避免跨画布撤销。
- 入栈时机：单任务 pointerup、单素材 pointerup、缩放结束、对齐/排列结束、删除成功后。
- 切换画布：**清空当前画布栈**（与实现一致）；不保留跨切画布的撤销历史。
- 删除撤销复用现有删除快照；图片在栈淘汰前不物理清理，避免“先清图再撤销”丢图。
- 最少 5 条 E2E：单任务移动、单素材移动、缩放、对齐、删除；一条失败注入：清图后撤销必须仍能恢复。

### 13.4 保存/导出契约（冻结）

- 单一 helper：stem 与扩展名分开清洗（stem 可截断，扩展名保留）→ 按输出格式白名单生成默认文件名 → 对话框过滤器/默认扩展名 → **对话框返回后、写入前**补扩展名。
- 白名单：`png/jpg/jpeg/webp/gif/svg`；`jpeg` 统一映射 `jpg`；未知 MIME 不得输出 `octet-stream`。
- GIF/SVG 是“本地转换”：API 仍只收 png/jpeg/webp；生成后本地转 GIF/SVG，再走保存契约。
- 默认目录、系统对话框、单图、多图、ZIP 全部共用同一 helper。

### 13.5 搜索/筛选/多选/网格落位（冻结）

- 侧栏头部搜索：只搜项目名；画布搜索留在胶囊/卡片视图头部。
- 卡片视图头部：任务内容搜索、状态/模型筛选、多选/批量、排序。
- 输入框右下：卡片视图/画布视图切换；右侧停靠时同样可见。
- 画布顶部只保留胶囊，不再有搜索/筛选/多选/视图切换。
- 搜索/筛选/多选落位覆盖画布、卡片、首页三种状态；“展开方案”在三种状态都可达。
- R7 按钮契约：全量静态扫描，关键路径 E2E，其余人工走查；不要求 165 个按钮逐一 E2E。

### 13.6 R8 live 证据脱敏

- 不记录 API Key、Authorization、中转站 token、完整请求头。
- 只记录：模型名、状态码、耗时、结果图片哈希、是否成功。
- 无凭据时 `known-limit`，不得写成 live 通过。
- 全部阶段结束后，除“明确不做/待拍板”外，总账不允许有 ⬜/🟡。

## 4. 预审闭环补充（2026-11-10）

### 4.1 U5-删除/批量契约（B06b）

- 选型：**内存撤销栈 + 引用计数保护**，不复用仅 Tauri 的 5 份删除快照。
- 删除前记录：任务完整 JSON、任务输出图 id、被删素材节点 id/imageId、原坐标。
- 撤销窗口内不物理删除图片文件；图片清理只删除引用计数为 0 且不在撤销栈中的文件。
- 栈上限 20 步，仅当前会话；重启清空。超过 20 步时最旧一步的图片才允许清理。
- 撤销恢复：任务写回 + 素材节点写回 + 坐标恢复；失败时保留栈项并提示，不假装成功。
- 失败注入：故意让图片清理先于撤销执行，验证撤销不丢图；恢复后绿。

### 4.2 B07 覆盖层与 ZIP（B07）

- 唯一权威字段：`Skill.source`（`builtin`/`mine`）；不新增 `origin`，避免双字段。

- 导出 manifest v4 增加**独立** `capabilityOverrides`；`capabilitySkills` 仍只含 mine。
- 导入：`capabilitySkills` 合并 mine；`capabilityOverrides` 合并覆盖层；同 ID 以导入覆盖层为准，内置不复制进 mine。

- 失败注入：清空 overrides 后收藏/封面丢失 → 单测必须红；恢复后绿。

### 4.3 B09b Gemini provider 契约（B09b）

- 接口：`generate(input): Promise<{taskId}>`、`poll(taskId): Promise<{status,images,error}>`、`cancel(taskId)`。
- 请求：模型、prompt、参考图（base64）、尺寸/数量；响应：图片 bytes 或 URL、修订提示词、错误码。
- 错误映射：401/403→auth，429→rate_limit，5xx→server，超时→timeout，内容拒绝→content_policy；全部落到现有 `classifyApiError`。
- 轮询：指数退避，最大 10 分钟；取消能中止轮询并标记任务。
- 验收分层：mock 必须通过；live 有真实凭据才跑，无凭据记 known-limit，不阻塞 mock 门禁。
