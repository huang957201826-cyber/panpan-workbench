## 1. 产品主线（先统一）

### 1.1 技能与提示词

- **技能**：镜头、光线、材质、构图、风格、负向词、推荐参数、参考图角色、不能改的结构。技能是“专业框架”。
- **提示词**：用户自己的对象、场景、氛围、要求。提示词是“具体内容”。
- **调用**：技能提供基座，用户只填 3–6 个槽（优先 2–3 个宽字段），最后与用户文字合并。
- **不要**：把技能做成一段更长的提示词；不要让技能覆盖用户已经写好的具体要求。

### 1.2 技能库页面

```
技能库
├ 技能（能力包）
│  ├ 每个技能一张封面图 + 名称 + 一句话 + 适用模型
│  └ 内置 8–10 个商业空间方向 + 我的技能
└ 提示词库（现有 PromptSkill 全部迁到这里）
   ├ 我的收藏
   ├ 分类
   └ 标签
```

- 技能卡片**顶部必须有图片**，用于快速检索。
- 技能库页面是管理/浏览；主调用入口是底部栏「选用技能」。
- 旧提示词数据不删，标记 `kind: 'prompt'` 迁入提示词库；导出/导入/ZIP 两者都包含。

### 1.3 底部栏

- 新增「选用技能」，位置在现有「保存为技能」附近。
- 弹窗 520–640px：搜索、左侧分类、右侧技能卡片、底部应用。
- 选完技能弹出 3–6 槽表单，填完预览最终提示词。
- 应用后输入框显示：**技能 chip（图标 + 技能名，可截断）+ 用户文字**；chip 可换/清。
- 提交时才展开技能基座 + 槽位值 + 用户文字；输入框里不铺全文。
- 底部栏控件过多：保留高频 6 个（模型、尺寸、数量、参考图、选用技能、发送），质量/格式/遮罩/链接/右侧停靠收进「更多」或第二行。

## 4. 我新发现的思路 / 风险

1. **C2 是跨平台问题，不是 Windows 小 bug。** Windows WebView2 和 macOS WKWebView 的 `<a download>` 都不可靠；统一走 `saveFile()`/保存对话框，才同时修 Windows 和未来 macOS。Web E2E 通过不等于安装版修好。
2. **U6 要先统一“选中态模型”。** 任务选中、素材选中、图片右键菜单是三套状态；空白点击必须同时清三套，否则 Delete 会误删。建议补一条 E2E：选中素材 → 点空白 → Delete 不弹删除框。
3. **技能 chip 需要自己的数据模型。** 输入框要存 `activeSkillId + slotValues`，而不是把整段 prompt 塞进 textarea；切换画布/重启时 chip 是否保留要明确；提交时再展开合并。
4. **技能封面是内容工程，不是 UI 小活。** 27 条技能文件里没有封面；要用我们自己的出图做封面，不能用 Lovart 版权素材。没有真实封面之前，先用分类色块/占位，不能空着。
5. **技能/提示词迁移要一次做对。** 旧 `PromptSkill` 标记 `kind:'prompt'` 进提示词库；新增 `Skill` 存储；导出/导入/ZIP 两者都包含；不做破坏性迁移。
6. **W1 和 Lovart 命名一起纠偏。** 工作流恢复；「Lovart」从用户界面移除，统一叫「技能库/技能」；数据源路径可以保留为内部实现。
7. **单一事实来源。** 这次最大的流程问题是：仓库 `LEDGER.md` 和 WorkBuddy backlog 是两套东西，B03 用了前者。建议把 WorkBuddy backlog 同步进仓库（或明确只认这一份），并给每条加“状态/证据”，避免再出现“以为改了”。
8. **“完成”的定义要包含安装版。** C2 就是教训：Web E2E 绿了，安装版仍是 `<a download>`。下载、拖放、剪贴板、输入法这类交互，必须至少有一次安装版验证。
9. **底部栏先做减法。** 现在模型、尺寸、质量、数量、格式、更多、参考图、遮罩、链接、从画布选、保存技能、右侧停靠、发送一排十几个；U3 加“选用技能”前，先把低频项收进「更多」，否则更挤。
10. **能复用的不要重写。** `testApiConnection()` 已经在请求 `/models`；`downloadImages.ts` 已有 zip 基础；`CanvasBoard` 已有框选；`SkillCover` 已有封面组件。M1/C4/U2/K1 都应在现有基础上接线，而不是新造一套。
11. **公开发布与本地安装分开。** 本机已是 1.0.1，公开仓仍是 1.0.0；下次发版按 patch 升版，禁止同号重建，先决定要不要公开 1.0.1。
12. **macOS 暂不排期。** 本轮只做评估，不进入 backlog 执行；先把 Windows 的 C2/技能/W1 收干净。
