# P2 映射规格：画布属性 → 条目 values → API 图锚点

- 日期：2026-11-16
- 适用：`ComfyWorkflowView` 真实执行（P2）
- 原则：画布上能改的属性是唯一输入；条目 `values` 只存可复用参数；引擎文件名不落库。

## 1. 三层映射

| 画布节点（显示类型） | 节点属性 | 条目 `values` 键 | API 图锚点 | classType / 输入 |
|---|---|---|---|---|
| `CLIPTextEncodePositive`（TextEncodeQwenImage21） | `text` | `prompt` | `__PROMPT__` | `TextEncodeQwenImage21.prompt` |
| `BasicScheduler`（KSampler） | `steps` | `steps` | `__STEPS__` | `KSampler.steps` |
| `BasicScheduler`（KSampler） | `denoise` | `denoise` | `__DENOISE__` | `KSampler.denoise` |
| `BasicScheduler`（KSampler） | `seed` | `seed` | `__SEED__` | `KSampler.seed` |
| `ImageScaleBy` | `scale_by` | `scale` | `__SCALE__` | `ImageScaleBy.scale_by` |
| `UpscaleModelLoader` | `model_name` | `model` | `__UPSCALE_MODEL__` | `UpscaleModelLoader.model_name` |
| `LoadBackgroundRemovalModel` | `bg_removal_name` | `model` | `__BG_MODEL__` | `LoadBackgroundRemovalModel.bg_removal_name` |
| `LoadImagePrimary`（LoadImage） | 运行时的引擎文件名 | `image`（不落库） | `__IMAGE__` | `LoadImage.image` |
| `MaskSource`（LoadImageMask） | 运行时的引擎文件名 | `mask`（不落库） | `__MASK__` | `LoadImageMask.image` |

- 负向提示词不进 `values`：四条已接通的 API 图里负向由同一 `TextEncodeQwenImage21` 的 `negative_prompt` 承担，当前 UI 只编辑正向。
- `seed = 0` 每次运行随机；运行结束后把实际种子写回节点与 `values`，方便复现。
- `batchCount` 不进 `values`：按次数串行提交同一张图，每次都要重新应用锚点。

## 2. 运行时顺序

1. 画布点「运行电池组」→ 从节点属性收集 `WorkflowRunRequest`（prompt / steps / denoise / seed / inputImageUrl / maskUrl / batchCount）。
2. dataURL 原图 → `Blob` → `File` → `uploadImage`，得到引擎文件名。
3. 需要蒙版的流程（manifest 有 `mask` 参数）：涂抹层先转成**黑底白区 PNG**，再 `uploadImage`；没有涂抹直接报错，不提交。
4. `applyParamValues(clonePrompt(API_WORKFLOW_BY_ID[presetId]), params, runValues)`；锚点按 `anchors.ts` 的 classType 定位，找不到即失败，不静默跳过。
5. `enqueuePrompt` → `waitForPrompt`（15 分钟超时，取消时 abort）→ `fetchOutputImage`。
6. 结果同时做两件事：`URL.createObjectURL` 给画布预览；`createInputImageFromFile` 入库拿 `imageId`。
7. 运行成功：`updateWorkflow(entryId, { results, lastRunAt, values })`；`results` 上限 24 条。
8. 历史胶囊与大厅归档都读同一条 `ProjectWorkflow`，不另建第二套历史。

## 3. 蒙版格式

- 涂抹层：橙色 `rgba(245,158,11,0.58)`，有笔画处 alpha > 20。
- 提交前：同尺寸画布逐像素判断 alpha，> 20 写白（255），否则写黑（0），alpha 固定 255，导出 PNG。
- `LoadImageMask.channel = 'red'`，白区重绘、黑区保留。

## 4. 失败与降级

- 引擎未连接 / 缺模型：运行前由 `probeEngine` + `fetchAvailableModels` 拦截，按钮提示缺模型数量。
- 上传、提交、轮询、取图任一步失败：顶部错误条显示原文，进度复位，不写历史、不写结果。
- 取消：`AbortController` + `interruptEngine()`；已排队任务仍会执行（known-limit）。
