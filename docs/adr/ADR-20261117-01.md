# ADR-20261117-01：回退三页 UI，改用 vendor + adapter 迁移

- 状态：已采纳
- 日期：2026-11-17
- 影响范围：设置、技能库、工作流三页 UI；迁移方式

## 背景

原型迁移连续五次未达成“可用 + 一致”：
- 组件被就地改写（哈希与原型不同，相似度 100% 是假指标）；
- 电话式验收：只看构建/测试/相似度，没点过按钮；
- 设置页存在大量空 handler，属半成品。

## 决定

1. **回退**设置、技能、工作流三页 UI 到 2026-11-16 17:20 之前的干净基线；
   保留已验证的后端成果（引擎自启、comfyClient、四条工作流运行、项目工作流存储）。
2. **迁移方式改为 vendor + adapter**：
   - 原型整个 `src/components` + `src/types.ts` 复制到 `vendor/prototype/`，**只读**；
   - 任何文件哈希必须与原型一致，禁止在 vendor 内改一行；
   - 数据、动作全部由 `adapter/` 注入；
   - 必须改的地方记为 patch，用脚本应用，逐条登记。
3. **审查顺序**：先回退并安装稳定版 → 扫基线六指标 → 在基线上做架构评估 → 再迁移。

## 复用来源（必填）

- 本地 `vendor/prototype/**` ← `aether-studio-canvas---ai-studio-edition (3)/src/**`
- 允许差异：无（vendor 内零差异）
- 适配差异：只存在于 `src/studio/adapters/**`

## 后果

- 升级原型 = 整体替换 vendor 目录，适配层不动；
- 像素与几何天然一致，因为代码同一份；
- 数据接线仍需人工点验，但不再污染组件。

## 回滚

`git revert` 对应提交；vendor 目录可整体删除。
