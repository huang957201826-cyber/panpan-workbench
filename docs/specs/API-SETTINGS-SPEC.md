# 「设置 → API」面板规格（给代码生成用）

## 任务

在现有 React 19 + TypeScript + Tailwind 3 桌面应用里，重做「设置 → API」面板。只写这一个面板组件，不引入新依赖，不引入新的颜色/字体体系。

## 背景

用户多为设计师，不熟悉 API。当前问题是：字段平铺、不知道先填哪个、部分内容藏在弹窗里。

## 设计原则

1. 所有内容常驻可见，不用多步弹窗、不折叠（高级项除外）。
2. 用编号标题明确顺序：1 选择来源 → 2 填写密钥 → 3 选择模型 → 4 配置名称。
3. 能自动推断的不问用户，能自动填的不让手输。

## 布局

一列，最大宽度 720px，左对齐，区块间距 20px。
每个区块：编号圆点 + 标题（14px / 600）+ 说明（12px，次要色）+ 内容。

### 区块 1 选择来源

两张并排卡片（等高、圆角 12、1px 边框）：

- A「我有 API 密钥」——主选项，默认选中
- B「从推荐服务商添加」——右上角徽标「含返利」，说明“还没有密钥可以先去注册”，下方链接「去注册 →」（新窗口）

选中态：边框主色 + 右上角对勾。
区块说明：“密钥只保存在本机；推荐服务商与你的配置分开存放。”

### 区块 2 填写密钥与地址

字段 1：API 密钥

- password 类型，右侧“显示/隐藏”切换
- 粘贴后按前缀识别：`sk-` → OpenAI 兼容；`AIza` → Google；其他保持不变
- 识别成功在下方显示灰字：“已识别为 OpenAI 兼容，地址已自动填写”

字段 2：接口地址

- 随识别结果自动填，用户可改
- 占位符 `https://api.openai.com/v1`
- 下方灰字：“末尾带 / 时按原样拼接，不补 /v1”

字段 3：测试连接（按钮，不是自动）

- 点击后发 `GET {地址}/models`，带 `Authorization: Bearer {key}`
- 地址不是 `https://` 时先弹确认：“即将向非加密地址发送 API Key，确认继续？”
- 结果用一行状态文字：测试中… / 已连接，可用模型 N 个 / 失败原因
- 失败提示要可操作：401 密钥无效；404 地址可能多/少 `/v1`；超时检查网络或代理
- **绝不要在输入框失焦时自动发请求**

### 区块 3 选择模型

- 测试成功：下拉框列出返回的模型 id，可搜索
- 没有列表：文本输入框，占位符“服务商未返回列表时手动填写，多个用逗号分隔”
- 下方灰字：“当前选择：xxx”

### 区块 4 配置名称

- 输入框，默认 `{来源名} · {模型}`，例如「特惠 API · gpt-image-2.5」
- 用户手动改过后不再自动覆盖
- 说明：“用于在首页模型下拉里识别，可随时修改。”

### 底部

- 主按钮「保存配置」（高 36、全圆角）
- 次按钮「取消」
- 保存后该配置出现在「我的配置」顶部并被选中

## 我的配置列表（面板上方）

- 每行：名称 + 服务商标签 + 模型 + 状态（已配置 / 缺密钥）
- 点击切换当前配置；右侧「⋯」提供复制、删除
- **推荐服务商永远不出现在这个列表里**

## 推荐服务商（广告位）

- 只在“一个配置都没有”时，在面板顶部显示一张引导卡
- 卡片必须写「含返利」；点“使用”只把地址填进区块 2，密钥仍为空
- 用户已有配置后引导卡收起，只在区块 1 的选项卡里保留入口

## 视觉规范（严格遵守，不要自创）

- 字号：标题 14/600，正文 13，说明 12，等宽数字 11
- 行高：正文 1.5
- 圆角：卡片 12，输入框/按钮 8，主按钮可全圆
- 间距：4 的倍数；区块 20，字段 8
- 浅色：背景 `#f3f4f8`，卡片 `#ffffff`；深色：背景 `#0c0e14`，卡片 `#161822`
- 边框：1px，浅色 `rgba(0,0,0,0.08)`，深色 `rgba(255,255,255,0.08)`
- 图标：lucide，16px，描边 1.5
- 深色模式必须同步适配

## 技术约束

- React 19 + TypeScript + Tailwind 3，函数组件
- 不新增依赖
- 受控组件，状态由父组件传入
- 组件签名：`<ApiSettingsPanel profile={profile} onSave={...} onCancel={...} onTest={...} />`
- 不直接读写 localStorage
- 所有文案中文

## 数据结构

```ts
interface ApiProfile {
  id: string
  name: string
  provider: 'openai' | 'sb2api-async' | 'fal' | 'google' | string
  baseUrl: string
  apiKey: string
  model: string
  selectedModel?: string
  timeout: number
  apiMode: 'images' | 'responses'
  codexCli: boolean
  apiProxy: boolean
  transparentBackgroundMethod: 'api' | 'local'
  description?: string
}
```

## 验收

1. 1440 宽窗口下，1–3 区块一屏可见，不需要滚动
2. 粘贴 `sk-` 开头的 key，地址自动变成 `https://api.openai.com/v1`
3. 点测试连接成功时，下拉出现模型列表
4. 配置名称默认「服务商 · 模型」，改过之后不再被覆盖
5. 非 https 地址点测试先弹确认
6. 失焦不发任何请求
7. 深色模式下无白色斑块
